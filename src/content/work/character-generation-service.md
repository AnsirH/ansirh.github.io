NC AI 사내 자율 연구로 혼자 만든 캐릭터 제작 워크벤치입니다. 기능마다 독립된 페이지가 있고, 각 페이지에서 그 기능을 실행합니다. 얼굴 리깅 자동화도 이 워크벤치의 한 페이지입니다.

## 기능

| 기능 | 입력 → 출력 |
|---|---|
| 파츠 이미지 생성 (Gemini) | 캐릭터 전신샷 → 얼굴, 헤어, 의상, 팔, 다리 등 파츠 이미지. 파츠마다 방향별 뷰도 함께 생성 |
| 3D 에셋 생성 (VARCO3D) | 파츠 이미지 → 3D 에셋 |
| 모델 편집 공간 (Three.js) | 생성된 에셋을 웹에서 배치하고 버텍스 편집, 스컬핑, 리토폴로지. 절단면을 맞추는 정합으로 파츠의 위치·회전을 결정 |

## 설계에서 지킨 것

- **외부 API는 서버를 거친다.** 브라우저가 외부 모델을 직접 부르지 않고 자체 서버를 경유합니다. API 키는 서버에만 있고, 외부 모델 URL과 파일 경로는 클라이언트에 드러나지 않습니다.
- **TDD 개발 루프.** 테스트가 실패하는 것을 먼저 확인하고, 구현한 뒤, Playwright로 화면을 검증하고, 피드백을 받아 고치는 과정을 반복했습니다.
